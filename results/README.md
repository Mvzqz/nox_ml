# Results

Run outputs used in the course deliverables (nov–dec 2023), copied from `runs/` (which is git-ignored).
Each folder holds the resolved `config.yaml`, `metrics.json`, `code_version.json` and, for models,
`oof.parquet` (out-of-fold station predictions) and `emissions.parquet`; tuning folders also hold
`trials.csv`. `comparison.md` / `comparison.csv` are `nox-ml compare results/runs/*/`.

Final configurations: `configs/experiments/<model>.yaml`. Tuning searches: `configs/experiments/*.search.yaml`.
