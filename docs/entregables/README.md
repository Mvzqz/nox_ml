# Entregables del curso

Esta carpeta reúne la documentación que pide el curso (equipo 39). El código, los datos y los cuadernos viven en el resto del repositorio; ver el [README](../../README.md) para la estructura completa.

## Dónde va cada entregable

| Entregable | Dónde | Estado |
|---|---|---|
| Semana 1 | `docs/entregables/semana-01.md` (o el PDF con el mismo nombre) | Pendiente de subir |
| Semana 2 | `docs/entregables/semana-02.md` (o el PDF con el mismo nombre) | Pendiente de subir |
| Semana 8 | `docs/entregables/semana-08.md` (o el PDF con el mismo nombre) | Pendiente de subir |
| Semana 9 | `docs/entregables/semana-09.md` (o el PDF con el mismo nombre) | Pendiente de subir |

Cada archivo enlaza a los cuadernos y a los datos que usa. Al subir uno, cambiar su estado en esta tabla.
